도파민 감옥 개인정보처리방침
최종 수정: 2026년 11월 3일

1. 적용 범위
도파민 감옥의 도파민 감옥 Android 앱에 적용합니다. 앱은 회원가입 없이 기기 안에서 집중 기능을 제공합니다.

2. 기기에 저장하는 정보
마지막 집중 세션의 시작 시각, 설정 시간, 선택한 앱의 패키지명, 종료 상태와 사유를 앱 전용 저장소에 저장합니다. 시간 표시 방식, 권한 안내 동의 여부, 오디오 기능과 Shorts 나가기 사용 설정, 내려받은 Shorts 감지 규칙과 마지막 내려받기 시도 시각도 저장합니다. 이 앱은 이러한 정보를 개발자의 서버로 전송하거나 제3자에게 제공하지 않습니다.

3. 접근성 권한
사용자가 별도 안내에 동의하고 Android 설정에서 서비스를 켜면, 집중 중 보이는 창의 소속 앱과 위치를 확인해 선택한 앱 영역에 차단 안내를 표시합니다. 창 식별 정보는 처리에 필요한 동안 메모리에서 사용하고 세션 종료·창 제거 시 정리합니다. 사용자가 ‘YouTube Shorts 나가기’를 켠 경우에만 집중 중 YouTube 창에서 Shorts 플레이어의 화면 요소 ID와 표시 여부·크기를 확인하고, Shorts 화면이면 이전 화면으로 이동합니다. 화면 텍스트, 입력 내용, 메시지, 시청 기록은 조회하거나 저장하지 않습니다. 장애인 지원 전용 접근성 도구를 표방하지 않습니다.

4. 알림 접근 권한과 미디어 제어
백그라운드 재생 일시정지는 기본적으로 꺼져 있는 선택 기능입니다. 별도 안내에 동의하고 알림 접근을 연결하면 집중 중 활성 미디어 세션에서 선택 앱을 식별하고 재생 상태와 지원되는 제어 명령을 확인합니다. pause 또는 stop을 요청하며 알림 제목·메시지·내용은 조회하거나 저장하지 않습니다. Android가 부여하는 알림 접근은 알림 내용에 접근할 수도 있는 넓은 권한입니다. 기능을 끄거나 세션이 끝나면 미디어 관찰을 중단합니다. 권한 자체는 Android 설정에서 별도로 해제할 수 있습니다.

5. 설치 앱 목록
집중할 앱을 사용자가 선택할 수 있도록 실행 가능한 앱 이름과 패키지를 기기 안에서 확인합니다. 전체 설치 앱 목록을 서버에 전송하지 않습니다. 전화·설정·홈·키보드 등 필수 앱은 차단 대상에서 제외합니다.

6. 외부 전송과 제3자 서비스
앱에 광고 SDK, 분석 SDK가 없습니다. 인터넷 권한은 ‘YouTube Shorts 나가기’를 켠 경우에만, 공개된 Shorts 감지 규칙 파일을 하루 최대 한 번 내려받는 데 사용합니다. 이 요청에는 계정, 기기 식별자, 세션·선택 앱·화면 정보가 포함되지 않습니다. 다만 파일을 제공하는 호스팅 서비스가 일반적인 웹 요청처럼 IP 주소와 요청 시각을 처리할 수 있습니다. 앱 자체에서 개인정보를 외부로 전송하거나 판매하지 않습니다. Google Play 등 플랫폼이 직접 제공하는 설치·결제·진단 기능은 해당 플랫폼의 정책이 적용됩니다. 문의 이메일을 보내는 경우에는 사용자가 보내기로 선택한 내용을 해당 이메일 서비스와 수신자가 처리합니다.

7. 보관 및 삭제
마지막 집중 기록은 다음 세션으로 대체되거나 사용자가 ‘나의 기록’에서 ‘로컬 기록 삭제’를 선택할 때까지 보관합니다. 진행 중인 세션은 먼저 종료해야 삭제할 수 있습니다. 기록 삭제는 마지막 집중 기록을 삭제하며 기능 설정과 권한 동의 값은 남습니다. 앱을 삭제하면 앱 전용 저장 데이터가 삭제됩니다. 앱 데이터의 클라우드 백업은 사용하지 않습니다. 권한 해제만으로 기존 집중 기록이 자동 삭제되지는 않습니다.

8. 사용자의 선택
접근성 서비스와 알림 접근은 Android 설정에서 언제든 해제할 수 있으며 앱 삭제를 막지 않습니다. 통화·알람·기기 볼륨을 변경하지 않고 집중 종료 후 자동 재생하지 않습니다. 미디어 제어 미지원 앱의 소리는 강제로 중지하지 않습니다.

9. 문의 및 변경
문의: Google Play 앱 등록정보의 개발자 연락처를 확인해 주세요.
처리 방식이 바뀌면 앱과 공개 개인정보처리방침을 갱신하고 필요한 경우 다시 동의를 받습니다.
